# Agino 屏幕键盘

当前0.1.21使用标准Qt光标处理；显示期间字体缓存正常复用。

DTK6 风格，默认完整数字行和可选 F1–F12，不显示独立标题栏。
候选行固定显示：标准模式占 48、紧凑模式占 32 逻辑像素；有候选时展示 16（紧凑模式 13）逻辑像素连续文字，以空白分隔、按内容计宽，支持横向滑动。右端居中的矢量下箭头展开覆盖主键区，选择候选或再次点箭头还原。左侧常驻屏幕键盘应用图标，右侧、设置/候选下拉按钮之前显示 Fcitx 提供的输入法名称及语言，例如“中文：拼音”；安全输入时显示“安全输入”。切换输入法同步更新状态；紧凑模式只显示语言缩写，例如 CN、EN、JA、DE，缺少语言元数据时显示破折号，安全输入时显示“锁”。有候选时隐藏右侧状态并将其宽度交还候选词；不显示预编辑字母。
不在键盘上显示预编辑字母。英文输入直接提交到光标处；中文输入通过应用的正常预编辑通道显示组合字母，选择候选后由输入法完成替换，不先插入并回删已提交字母。
显示期间，输入法将字母放在输入面板预编辑、而非客户端预编辑时，桥接在支持预编辑的应用中临时路由到客户端；收起、切换焦点、暂停或发送方退出时恢复原显示状态，不更改用户输入法配置。
显示面板期间候选只在屏幕键盘中显示；收起、退出或进程异常断开时恢复普通输入法候选窗口，保留当前组合。
搜狗 NG（已验证 10.0.10.0-1403）通过 CPIS 最终 keyflow 候选接入同一候选行；预编辑只在支持预编辑的目标应用光标处显示。选择、翻页和分段选词仍由搜狗处理。仅在键盘拥有显示租约时接管 composition 窗口，不改搜狗预编辑配置；收起或键盘连接断开时发送恢复命令。候选更新期间拒绝过期索引，接口失败时恢复原面板。其他版本的搜狗及旧 Fcitx4 搜狗尚未验证。
无候选时，较小、细线的设置图标显示在候选行最右端；有候选时同一位置显示候选展开箭头。主键区不再有设置键，左 Shift 延长一列，与右 Shift 等宽。地球图标位于原 Caps 位置，用于循环切换已配置输入法。移除 Caps 和四个方向键；底行最右端为收起键。
连续两次短按 Shift（抬起间隔不超过 400 ms）切换大小写锁定，单击 Shift 高亮并修饰下一次成功输入，随后自动取消；锁定时两个 Shift 高亮并显示“↑ Shift”，数字及标点持续使用上方符号；长按、与字母组合、取消或期间输入其他键不会误锁定。普通 Shift 修饰仍可用。
鼠标或触摸按住任意普通键、功能键、状态行或空白边缘并拖动，可移动键盘。超过 16 逻辑像素后取消当前按键，其他手指也不能触发键位、候选或设置；候选词的横向/展开区纵向滑动继续用于浏览。点击空格键输入空格；设置、切换和收起操作在无编辑目标时仍可用，普通输入继续受后端编辑状态限制。
候选出现、选择或消失时，窗口高度、位置和按键尺寸保持一致；浮动窗口仍限制在当前屏幕范围内。
标准模式高度固定为 344（开启 Fn 为 400）逻辑像素，宽度按屏幕取 828～934；紧凑模式为 524×208（开启 Fn 为 524×242），不再提供屏幕高度比例设置，旧配置不影响尺寸。浮动时释放桌面预留空间，本进程收起、界面卸载和重新呼出后保留位置；退出进程后恢复底部居中。
标准模式键高固定 48 逻辑像素；紧凑模式基础按键为 32×32，横纵间隔 2，保留 DTK 配色，普通字符在有效抬指后提交；双指修饰和长按变音字符可用，向变音栏移动时保留选词路径，拖向别处则移动窗口。退格使用矢量图标；轻点抬起时删除，长按 450 ms 后开始成对连删，每 60 ms 一次，拖动或取消后停止。窗口底色透明，由主面板绘制圆角。 X11 的 Deepin KWin 会话通过现有 DTK 原生无标题栏接口显示系统窗口阴影，圆角随标准/紧凑布局更新，保持按键与窗口尺寸；不启用 DTK 的额外父窗口、系统拖动或系统缩放。无合成时保留原生圆角裁剪。Wayland layer-shell 阴影尚未适配。

`agino-keyboard` 手动打开，`--hidden` 隐藏常驻，`--settings` 打开同一键盘窗口内的 DTK 设置面板；已有进程时转到该进程，不创建独立设置窗口。
默认快捷键 Ctrl+Alt+K，可在设置中修改；无修饰键或注册失败会记录到 Status 的 shortcutError。按快捷键切换显示/隐藏，设置页已打开时也可用快捷键收起；松开按键及普通实体按键不会误收起或重新呼出。右下角收起键只隐藏本次键盘。
已显示的屏幕键盘不会因实体键盘按下、释放或切换输入焦点而收起；失去可编辑目标时取消按住的键并暂停输入，保留面板显示。输入法后端发出的自动隐藏通知只取消触点并刷新编辑状态。主动关闭、关闭模式、锁屏、后端断连或尺寸不足仍会收起。实体按键不会自动呼出已隐藏的面板。
隐藏启动先注册托盘、快捷键和输入服务，首次呼出时再创建键盘窗口和界面。
键盘和设置默认使用 QtGui/QPainter 原生栅格绘制，DTK 配色、布局和输入协议保持不变。Qt Quick 前端仅保留为显式参考目标，其图形后端环境设置不影响正式原生前端。
收起满 1 秒后请求回收渲染资源，满 3 秒后销毁窗口和 QML 并退出界面进程。轻量 QtCore 控制器保留托盘、快捷键、触屏来源与 DBus 接口，收起后不加载 Qt GUI/QML/DTK；短暂收起保留界面。持续收起后再次呼出会重建界面进程，保留浮动位置与大小写锁定。显示期间测量内存须汇总控制器和界面进程，不能只统计控制器。
收起优化审阅并验证于 Qt 6.8.0；字体缓存清理使用 Qt 内部钩子，升级 Qt 后必须重新审阅并验证重绘、输入及内存。
更多候选词面板仅在展开时创建，收起或选择后释放其对象；候选条继续按内容计宽和横向滑动。
设置覆盖整个键盘窗口（包括候选行），以两列显示十项：呼出方式、默认输入法、安全输入、快捷键、按键声音、布局模式、功能行、屏幕、主题和不透明度。标准模式设置行高 48，紧凑模式 28 并使用更小字号；所有选项在各模式的最小窗口内完整可见；打开设置时隐藏候选行与按键，窗口宽高不变，返回后恢复。候选展开层与设置互斥。进入设置取消按住键并暂停虚拟发键，返回后恢复键盘，组合与候选不会因打开设置而提交或清空。收起、锁屏、断线时关闭并卸载设置层。
紧凑模式的快捷键编辑器在同一窗口内滚动；不扩大窗口。快捷键通过内嵌选择器选择修饰键和字母、数字、F1–F12；至少选择一个修饰键，避免抢走当前输入框的焦点。关闭模式仍可通过托盘设置或 `--settings` 修改配置，返回后保持关闭。输入法名称和语言自动查询并缓存，列表只包含已配置的输入法；临时查询错误以有界退避重试，断线停止，持续错误不循环请求。
不透明度默认 100%，可调 50%～100%，同时作用于候选行、按键和设置页。X11 无桌面合成时保持不透明，控件提示“需要桌面合成”；偏好仍保留，开启合成后应用。Wayland 使用透明 surface。
按键声音默认关闭，开启后播放自有的 12 ms 轻提示 WAV。libcanberra / libcanberra-pulse 在独立工作线程连接并播放；切换关闭不等待音频线程。默认关闭时不创建音频上下文或线程。声音跟随音频系统的音量/静音设置，不连接输入法引擎获取字符。
默认输入法仅在启动或修改设置时应用，地球按钮和外部输入法切换会保留用户的新选择。
安全输入和锁定状态会在后端恢复后重新同步，确认成功前不接受按键，也不重放旧输入。
界面连接退出时释放其按住的修饰键；屏幕缩放或功能行改变导致键位无法容纳时取消输入并收起面板。

需要 Fcitx5 和本包的焦点插件，不能同时占用其他独立屏幕键盘的 DBus 服务。
Deepin 搜狗 CPIS 在 Fcitx 自身的 DBus 连接中提供虚拟键盘界面时，本应用使用独立输入桥接，保留该界面及其配置；不强占服务，也不启用或重载 Fcitx 虚拟键盘模块。
缩放策略在创建应用前应用，保留系统设定及对子进程的环境传递，避免 Qt 6.8 的初始化顺序警告。
用户输入、候选、预编辑只存在会话内存中，不记入日志。
已知密码和手动安全输入直接提交普通字符、成对转发控制键，绕过输入法引擎，避免候选及学习。

Wayland 停靠由本包内的 `agino-keyboard` Qt shell 插件实现，不依赖 layer-shell-qt 或 liblayershellqtinterface6。
插件初次显示底部居中、顶层显示、不抢键盘焦点和按高度预留空间；拖动为浮动状态后不再预留空间；设置面板沿用键盘的 Wayland 层，不抢输入窗口焦点。
插件只针对 Qt 6.8.0 私有 ABI 编译，deb 声明对应 Qt base/Wayland client ABI 约束；升级 Qt 时须重新编译验证。
协议 XML 保留上游版权，wlr 的 namespace 参数仅为 Qt C++ 生成器改名为 scope，不改变线上的协议。

X11 使用 `agino-keyboard-fcitx-x11 --replace -d` 启动匹配的 Fcitx5；Wayland 由 KWin 启动唯一 Fcitx5。
在 KWin 虚拟键盘设置中选择 `agino-keyboard-wayland.desktop`。
包内设备来源插件由 KWin 加载，仅传递鼠标/触屏/笔/实体键盘来源，不传递字符；未加载时降级手动。
独立 Wayland 前端保留虚拟按键的按下/释放与修饰状态，支持原生文本输入 v2/v3。
该入口为 Deepin KWin/Fcitx5 协议冲突设置 DetectApplication=False，保留其他配置；
代价是关闭 Fcitx 按应用识别。无需共享 WAYLAND_SOCKET 给键盘界面。
不要同时从其他自启动入口再启动 Fcitx5，不用于登录或锁屏输入。

构建：仓库 `scripts/build-screen-keyboard.sh` 在隔离容器中构建和测试，输出独立 Debian 包。

## 当前实现

`agino-keyboard` 是轻量常驻控制器，`agino-keyboard-ui` 使用 QtGui/QPainter 和 DTK 调色板绘制界面；警告对话框按需启动 `agino-keyboard-dialog`。隐藏后界面进程退出，再次呼出时重建；输入期间正常复用有界文字缓存，光标由 Qt 标准路径处理。

图标由 SVG 生成 1–192 像素 PNG，按实际 DPR 选择，避免普通尺寸下额外加载 SVG 渲染库。它们均被 native.qrc 引用。修改 SVG 后可构建 `rasterize-appicon` 并在匹配 SDK 中重新生成。

`qml/`、`panelview.h` 和 `keyboardiconprovider.h` 仍用于现有 QML/窗口回归测试，正式程序不加载 QML；已删除未使用的旧 Qt Quick 应用入口。完整测试还覆盖原生设置、绘制、无障碍、候选选择、搜狗、X11 和 Wayland。
