# 屏幕键盘 0.1.12：紧凑布局、透明度和按键声音

2026-10-05。基线 0.1.11（48094ba）。原始构建、回归、实际桌面截图与包记录位于 `out/components/agino-keyboard-validation/compact-012/`。本轮没有安装主机软件、重启主机键盘/输入法，或调整主机合成设置。

## 布局与设置

默认仍是标准模式。删除屏幕高度比例属性和滑块，旧的 heightPercent 配置被忽略。

| 模式 | 窗口宽度 | 高度 | 开启 Fn 的高度 | 基础按键 | 键间距 |
|---|---:|---:|---:|---|---|
| 标准 | 828～934 | 344 | 400 | 高 48、宽度随窗口分配，最小 48 | 横 6、纵 8 |
| 紧凑 | 524 | 208 | 242 | 32×32 | 横纵 2 |

以上为逻辑像素；200% 时物理像素翻倍。标准宽度沿用屏幕自动选择规则。候选行标准 48、紧凑 32，始终保留，候选词按内容计宽且使用连续文字。改变候选、打开设置都不改变窗口或键高。DTK 配色、键位、加长 Shift、地球键、收起键、双 Shift 锁定与拖动逻辑保留。

设置覆盖整个键盘和候选行，两种模式都用两列完整显示十项：呼出方式、默认输入法、安全输入、呼出快捷键、按键声音、布局模式、功能行、屏幕、主题、不透明度。标准行高 48；紧凑行高 28，标题/控件字号 10～11，取消较小空间里的辅助说明。快捷键编辑子页在同一窗口内滚动，不把窗口变宽或变高。

## 透明度和声音

不透明度默认 100%，范围 30%～100%，实时作用于整个键盘及设置；保存偏好，隐藏后重新呼出继续使用。

X11 未开启合成时，透明像素无法与桌面混合，因此显示“需要桌面合成”，保持不透明而不更改用户的偏好。PanelView 同时检查 DTK 合成状态及标准 compositor selection。XFixes 通知即时跟踪合成器启动、退出和连接关闭，清除或恢复原生圆角裁切，并恢复或停用透明度；不轮询。Wayland 继续使用透明 surface，不走 X11 原生裁切。实际私有 xcompmgr 起停重启和像素混合均验证。

按键声音默认关闭。启用后通过 libcanberra 播放自有 12 ms WAV，运行时明确依赖 libcanberra0 / libcanberra-pulse。连接和播放位于独立工作线程；关闭立即取消后续请求并异步退出线程，不在 GUI 线程等待音频服务器。旧线程的回调按代数失效，进程退出时才等待清理。默认关闭不创建音频上下文或线程，音量与静音仍由音频系统控制。

## 验证与交付

- 增加 QML 测试，在原版本上因缺少布局选择器真实失败。修复后检查紧凑 32×32、2 像素间隔、208/242 与标准 344/400，十个设置控件在各自窗口内完整可见；还覆盖持久化、快捷键编辑滚动、候选宽度、固定几何、触摸拖动与透明度不可用时的回退。
- 原生 Fcitx/Qt 测试覆盖 X11、Wayland v2/v3、XWayland 的实时模式切换、Fn、设置不改变窗口、隐藏卸载再呼出以及输入焦点。旧比例值 70 不再改变标准高度。现有中文预编辑、候选、搜狗 NG 与 GTK 目标回归继续通过。
- 专用音频测试连接私有 Unix socket，服务器不响应时关闭声音小于 100 ms；随后连接私有 PulseAudio null sink，通过 monitor 实际录到非零点击信号（最终峰值 243），不连接主机音频。
- 实际 xcompmgr 在面板已经显示时启动、停止、再启动，核对 transparencySupported、native mask 和实际桌面 RGB 混合；100%/200%、圆角、DPR 变化都通过。
- 最终完整 CTest **35/35** 通过，292.40 秒；仓库 unittest **16/16** 通过。独立审阅发现的声音关闭等待和通用 X11 合成通知问题均已修复并复审通过。
- 截图使用交付包对应的 strip GUI，在匹配 Qt 6.8.0 / DTK6 SDK、私有 Fcitx、GTK 目标与 Xvfb 桌面中生成。包括标准/紧凑、Fn、设置、实际中文候选、深色、65% 透明度及 200%。PNG 捕获真实桌面，加 16 逻辑像素背景边距，不是 HTML 或 AI 设计稿。
- deb 声明 Qt/Fcitx/KWin 匹配 ABI，六个 ELF 无 LayerShellQt 链接。主机 apt 安装模拟仅升级 agino-keyboard，新增软件包数为 0；声音依赖已在本机安装。精确大小、依赖、源码/二进制校验记录见 package-provenance.json。

应用源码、完整仓库快照、匹配 Fcitx/KWin 上游源码及许可证随预览归档提供，不分发搜狗二进制。完整 DDE Wayland 会话、真实触屏/笔、旋转、多屏热插拔及休眠未做本轮整机验收；本包用于本机测试，release_ready=false。

安装后退出旧键盘进程再启动新版本。桥接输入代码沿用 0.1.11，本轮无需为界面调整强制重启当前输入法。
