实际 SDK 使用 Dtk6::Declarative、Fcitx5::Core、LayerShellQt::Interface、KF6::GlobalAccel。
安装版虚拟键盘接口保存在 `apps/agino-keyboard/tests/protocol-contract.xml`。
输入上下文与候选代次由会话插件校验，所有者变化清空客户端状态，不重放旧键。

包内包含原生程序、焦点桥、独立默认关闭的 Wayland 前端、XCB 兼容模块、设备来源插件、入口和许可证。
Wayland 前端与 XCB 兼容模块基于同一份签名 Deepin 源码，原系统模块不变。
XCB 模块仅通过专用入口的 FCITX_ADDON_DIRS 使用；原型为新用户配置自启动覆盖文件。
构建输出 upstream/ 保存 Fcitx/KWin 对应源码、发行版补丁和校验，应与应用源码归档一并分发。
不包含 root helper 或 uinput 服务。

## 查出的兼容问题与处理

- 普通字符经输入法引擎处理后按 UTF-8 提交；控制键/快捷键保留按下与释放，解决 Deepin Qt 的 ForwardKey 窗口转发丢失。
- X11 注册的两种传输可能先收到 FocusIn 再关联焦点组；兼容模块在同一上下文关联时保留原已确认焦点。
- 无关能力更新不清除按键；用途改变、实际焦点/所有者更换仍取消旧输入。
- 后端替换时排队接管桥服务；保存弱引用，避免输入上下文销毁后退出崩溃。
- 重复“未锁定”通知保持焦点和手动显示；解锁重新校验 SDK 当前焦点，旧代次仍无效。
- 当前 KWin 的 plasma-window 扩展与 Fcitx 应用检测不兼容，专用 Wayland 入口关闭 DetectApplication；代价是失去按应用记忆输入法。
- 当前 Deepin Qt v3 在切换窗口时可能暂时保留旧用途，键盘继续安全输入；普通输入测试先显式提交目标用途。未重新提交用途的应用可能暂时无法切换中文输入。

完整桌面的测试夹具先等待 Fcitx SDK 确认目标程序取得焦点，再读取当前快照；不能仅把 Qt 本地 hasFocus 当成后端已完成注册。窗口隐藏后桌面本身仍可成为可编辑目标，断言因此检查旧代次失效，只有私有空会话要求全局 editable=false。旧失败日志仍保留；“服务所有者订阅竞态”未获证实，未加入猜测性修复。

最终审阅的五项问题均加入失败回归再修复：首次/重连安全策略、重叠修饰键释放、发送者断连、默认输入法反复覆盖、尺寸变化取消。安全策略同步成功并获取其后快照前拒绝按键，不补发旧键。Wayland 用当前仍按住的左右修饰键推导状态，不从过期按下快照恢复已释放的 Ctrl。

## 优化前预览（344fb05）的资源与交付

最终安装包 SHA256：`b6b53ba179614b6b67c73b9751ce85d771f459ec9ea357443a391ead76e9dde9`。
应用源码提交为 `344fb05`，干净构建 13/13 CTest 通过，仓库 16/16 unittest 通过。
包大小 381,412 字节，Installed-Size 1,912 KiB；依赖复用匹配的系统运行时。
源码和签名上游源码/补丁、许可证随构建输出保存，分发时必须一起提供。

整机用 MemTotal - MemAvailable 计算，三次真正冷启动，每次等待桌面稳定 120 秒后采样 60 个样本，上限 1,000,000,000 字节。最终峰值为：

| 冷启动 | 峰值（字节） | 内存门槛 |
| --- | ---: | --- |
| 1 | 1,036,431,360 | 未通过 |
| 2 | 1,034,309,632 | 未通过 |
| 3 | 1,034,833,920 | 未通过 |

因此内存状态为 failed，`release_ready=false`。隐藏程序确实尚未创建窗口和 QML（viewCreated/panelLoaded 均 false），但整机仍超过目标。首次采样后的关机等待受系统 90 秒服务停止宽限影响，测量工具原 60 秒等待超时；确认正常卸载文件系统及 ACPI 关机后继续第二、三次启动。首轮样本保留，没有替换或缩短采样。

| 状态 | 键盘 RSS（字节） | CPU tick 增量/秒（100 tick/秒） |

首次本地 DBus Show 调用耗时 108.2 ms；它包含窗口与界面创建，但不等同于首帧绘制时间。使用后保留已加载界面，RSS 不返回启动时水平。
样本为 `memory/boot-{1,2,3}.json`、`memory/summary.json` 和 `runtime-resources.json`；旧失败样本另存，不能用于替代最终结果。

不支持未接入 Fcitx 可编辑接口的应用与桌面全局快捷键。缺少来源信号时降级手动模式；缺少 layer-shell/文本协议时明确拒绝停靠。

登录、锁屏输入不属于首版范围。当前原型调试 SSH/自动登录设置也不属于发布配置。
