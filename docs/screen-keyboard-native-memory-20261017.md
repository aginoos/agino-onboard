# Agino Keyboard 0.1.19 原生界面内存验收（2026-10-17）

最终结论：同机完整应用对照中，X11通用xcb、deepin dxcb+KWin和Wayland真实1×/2×输出的全部状态USS/PSS中位数通过。首次周期、后续周期及总体分别检查；RSS仍明显高于Slint，没有宣称RSS追平。新deb保留原界面和输入功能，51张真实窗口截图与0.1.18逐像素一致。

## 已验证的实现

- QtGui/QPainter默认界面，Qt Quick作为显式参考目标保留；前端没有直接QtQuick/QML依赖。
- X11约64KiB分带输出；Wayland共享内存BackingStore；候选仅布局可见前缀。
- 有界文字布局缓存；无触点、无绘制的空闲1秒后回收Qt字体缓存。固定Qt6.8私有ABI，升级必须复验。
- Wayland选择性加载静态箭头；动画、混合/强制/分数缩放、不确定主题或服务端cursor-shape支持使用Qt原路径。热点按QPoint取整规则保持。
- 稀疏无障碍虚拟控件，保留候选、设置、滑块、状态和过期对象安全性。
- 对话框改为按需独立helper；输入策略、Fcitx桥和KWin插件保持既有实现。
- 修复窗口状态元数据冗余写入触发compact配置回写竞态。

## 验证边界

51张实际截图与0.1.18逐像素一致，包含标准/紧凑/Fn/明暗主题与DPR1、1.25、1.5、1.75、2。保留未跳过的圆角底层绘制；曾尝试跳过并因116–733像素变化撤销。

全56项CTest第一轮54通过、2失败；尺寸警告竞态已重复复现并修复，相关9组回归通过。旧Quick参考阴影测试为瞬态失败，原始用例后续4次、诊断5次、去除诊断后1×/2×通过；没有声称已完全归因。最终冻结原生13组CTest全部通过。NativePanel 25项、光标16项均有ASAN/UBSAN/泄漏复核；SDK个别PIE sanitizer在main之前启动失败单独保留，最终非PIE测试通过，未修改发布PIE策略。真实AT-SPI20项通过；Qt6.8部分无障碍事件实现限制和未测Orca仍保留。

真实Fcitx X11/Wayland/v3均25通过、15条件跳过；搜狗X11为9通过，其余Wayland/v3/Xwayland各8通过、1项X11特有信号跳过。

## 测量约定

统计每版所有应用进程（控制器、界面及后代），RSS/USS/PSS求和；共用私有Fcitx、GTK目标、Xvfb/KWin不计入两版应用，但没有遗漏应用后代。原始Swap、SwapPss、VmSwap必须全0。标准934×344逻辑尺寸、关闭Fn、浅色、100%不透明、无按键声音、手动模式。Slint为0.2.3已交付二进制。顺序Slint→Qt→Qt→Slint，首次输入和后续输入分别验收，不用暖缓存掩盖首次开销。

X11通用xcb每cohort3个完整周期；真实dxcb+KWin每cohort1个完整周期，用于额外冷态/阴影复核。Wayland真实1×/2×每cohort3个完整周期；两版客户端缩放环境为1，缩放由合成器协议提供，2×窗口缓冲均1868×688。每个周期实际鼠标英文输入15字母、中文拼音5键、真实候选出现/展开/选择提交、设置、收起；活动采样与空闲1.5秒采样分列。收起4秒后采样是界面进程已退出后的常驻状态。

门禁是各状态首次、后续及总体中位数Qt USS/PSS不高于Slint；RSS单独报告且仍未达到Slint。此为同机本次条件结果，PSS分摊随系统同类库的其他进程变化，不冒称任意环境永远不高。

## RSS差距与适用范围

Wayland1×活动Qt只读smaps复核中，界面进程的共享库映射RSS36,732KiB，而这些映射PSS5,986KiB、USS3,044KiB；控制器共享库RSS13,324KiB、PSS1,567KiB。整个应用RSS还会重复累计控制器和界面共同映射的库页。数据证明差距主要来自Qt/DTK及其依赖的驻留共享页，不能把这部分RSS当作额外独占内存，也没有据此删除RSS指标。详情`wayland/formal-1x-active-qt-maps.json`。

本次资源验收是均匀整数1×/2×输出。分数DPR的界面像素通过，并不代表分数/混合显示器或动画光标主题的资源数字相同；此类光标条件保留Qt原路径，可能有额外光标缓存。系统端cursor-shape协议分支只有策略单测，当前KWin不支持该协议，未冒称真实服务端测试。Qt6.8无障碍事件边界见仓库AT-SPI说明，未做Orca完整读屏器验收。

历史0.1.18报告中200%中文候选PSS42.50MiB、展开54.30MiB、设置55.16MiB。新旧采样方法存在直接发送与真实指针输入等区别，因此这里保留历史数值供定位，不据此计算严谨的同条件降幅；本报告Qt与Slint采用同一组完整实际输入条件。

## 呼出代价

X11正式采样中Qt界面内部首帧提交约17.7–46.9ms，脚本从Show请求到观察首帧约85.7–140.4ms；后者含DBus和40ms轮询，不能视为精确端到端触屏延迟。Slint内部首帧约7.1–21.4ms。收起回收界面进程后，再次呼出会重建界面；未以保留不可见大界面来掩盖这一成本。
