# 屏幕键盘候选条与拖动修复（0.1.4）

2026-10-04，基线为 0.1.3，保留方案五键位、DTK 配色和收起释放资源行为。

## 行为

- 候选条使用 14 逻辑像素文字，没有独立按钮背景，按实际文字宽度计宽；保留至少 48 像素触控范围、横向滑动和右侧下箭头展开。
- 无候选、输入预编辑、生成候选和安全输入均保留 76 像素候选区，主键区尺寸不随这些状态变化。
- 拖动标题中央移动面板，设置、关闭按钮各保留 48 像素操作区；浮动位置限制在所选输出中。隐藏超过 3 秒卸载界面后，重新显示保留位置；重新启动进程恢复底部居中。
- 浮动时清除 X11 strut 或设 Wayland exclusive zone 为 -1，恢复最大化应用的桌面空间，并保持输入目标焦点。
- 面板显示期间接管 Fcitx 输入面板显示回调，候选和预编辑数据仍留在原输入上下文。关闭或发送方断开时恢复原回调及普通候选窗口，不清空组合、不修改输入法配置。
- 输入法自动 Hide 通知只取消触点并刷新编辑状态，防止物理键、鼠标或 FocusOut 再次把用户已呼出的面板收起。显式关闭、托盘收起、关闭模式、锁屏、后端断开和尺寸不足仍会收起。

## 原因与边界

Fcitx 的候选数据共享和候选窗口显示是不同路径。GUI 原先只读取数据，未控制普通 UI 的显示；Deepin CPIS 自己拥有虚拟键盘服务时尤其容易出现重复候选窗口。本次按发送方连接建立显示期接管，使用最高优先级 customVirtualKeyboardCallback；在 UI flush 前重新安装以处理引擎 reset，在焦点切换和进程断开时恢复。使用一个空的未聚焦上下文通知当前 UI 隐藏已经显示的窗口，不重置目标应用的预编辑。

Qt 6.8 把普通 Wayland 顶层窗口的位置固定在输出原点，layer-shell 不提供窗口坐标回报。插件从自己设置的锚点、边距和输出几何维护停靠及浮动的 Qt 平台几何，保持连续拖动的 mapToGlobal 坐标。参考 [Qt 6.8 官方实现](https://raw.githubusercontent.com/qt/qtwayland/v6.8.0/src/client/qwaylandwindow.cpp)。Deepin KWin 6.1.38 还依据 layer namespace 决定 NET 窗口类型；使用 dock，避免把屏幕键盘作为普通窗口移到自身预留区域上方。该规则已从构建包对应的签名 KWin 源码 src/layershellv1window.cpp 核对，并以嵌套 KWin 实际鼠标事件验证。

所有候选数据、按键与输入文本只存在会话内存。回归日志使用自建空白输入目标和测试字符串；本机输入法未被自动重启。

## 验证证据

证据位于 out/components/agino-keyboard-validation/candidate-drag/。

- 完整 22 项 CTest 覆盖 X11、原生 Wayland v2/v3、XWayland、后端重启、输出切换、焦点/安全输入、界面卸载和内存回收，以及新增候选接管与真实 Wayland 标题拖动。
- 私有 GTK + Pinyin 回归检查：显示前普通候选窗口可见；显示后窗口隐藏且候选/预编辑完全保留；继续虚拟输入仍只有面板候选；收起与强制结束 GUI 后普通窗口恢复；其它发送方不能取消当前接管。
- X11 标题按下、移动和释放后位置准确；卸载再显示保留位置；边缘限制、窗口变大及连续四次 0.25 逻辑像素移动得到验证。测试窗口查找同时支持无 WM 和真实 WM 重设父窗口。
- Wayland 协议 peer 验证 100%、150%、200% 的逻辑坐标/原生边距转换、top+left 锚点、exclusive zone -1、keyboard interactivity none 和输出删除恢复。
- 嵌套 Deepin KWin 实际鼠标连续移动 (-30,-50)、(-60,-100)，终点准确且焦点保留；实际物理 t 键输入成功后面板仍可见。双输出验证浮动释放预留空间、隐藏卸载后仍保持浮动状态。
- 新包在隔离完整 DDE X11 桌面安装；14 项候选弹窗、标题拖动和输入回归通过。SDK 的 backend-owned UI fixture 和 DDE 的普通 UI 分别覆盖两种服务所有权路径。
- QEMU 硬件键盘的冷/热/卸载后/较长按住快捷键四组回归全部通过：Ctrl+Alt+K 抬起后保持显示，普通输入、Tab、方向键、修饰键、Esc 和 F2 均不收起面板。
- 仓库 16 项测试；deb 的 6 个 ELF 均无 LayerShellQt 依赖。本机 apt 模拟安装只升级 agino-keyboard，不增加其它包。

真实触屏、笔、旋转、显示器热插拔、休眠及完整 DDE Wayland 会话仍需要设备验收；嵌套 KWin 测试和 QEMU 键盘事件不代替这些项目。其他 compositor 和额外 layer-shell 面板组合未单独验收。此次未重新测量 PSS，保留原收起优化并通过其回归。
