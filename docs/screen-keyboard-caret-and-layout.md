# 屏幕键盘 0.1.6：光标预编辑与布局调整

日期：2026-10-04。延续方案五 DTK 外观、完整数字行、可选功能行、触摸输入和自有 Wayland shell。

## 行为

- 英文普通字符提交到应用光标。中文组合字母通过正常客户端预编辑通道显示在光标处；选择候选后由输入法提交中文并替换组合，不先提交字母再回删。键盘上不显示预编辑字母。
- 候选行只在有非安全候选词时出现，保持 14 逻辑像素文字、内容自适应宽度、空白分隔、横向滑动和更多候选覆盖面板。右侧下拉图标改为居中矢量绘制。
- 移除 Caps 和上下左右方向键。地球图标占原 Caps 位置，循环切换已配置输入法；设置占原中/英位置；最右下角收起键只隐藏面板。
- 连续两次短按任一 Shift 切换大小写锁定，锁定时 Shift 高亮。单次按住不超过 350 ms，两次抬起间隔不超过 400 ms。字母组合、其他按键、取消、失去编辑目标或长按会取消连击识别；普通 Shift 修饰继续生效。
- 点击空格输入空格；拖动空格键移动面板。移动达到 16 逻辑像素后取消本次按键，不提交空格。
- 候选行出现时面板增加 48 逻辑像素，消失时减少；按键尺寸一致。同一输出上的浮动面板保留底边，因此按键位置一致，隐藏卸载后候选状态改变再呼出也保留该关系。屏幕边界限制仍优先。

## 预编辑路由

Fcitx 拼音可以配置将预编辑放在输入面板，而不发送给客户端。屏幕键盘可见、输入目标非安全且支持 Preedit 时，桥接临时复制输入面板预编辑到客户端预编辑，并通知应用。收起、切换焦点、暂停或发送方退出时恢复原客户端预编辑；仅当当前文本仍与本桥接写入内容一致时恢复，避免覆盖输入法后来产生的新内容。不修改用户配置，不向日志写入输入。

依据匹配的上游源码：[Fcitx 5.1.12 InputContext](https://raw.githubusercontent.com/fcitx/fcitx5/5.1.12/src/lib/fcitx/inputcontext.cpp)、[拼音 5.1.6 实现](https://raw.githubusercontent.com/fcitx/fcitx5-chinese-addons/5.1.6/im/pinyin/pinyin.cpp)、[拼音配置](https://raw.githubusercontent.com/fcitx/fcitx5-chinese-addons/5.1.6/im/pinyin/pinyin.h)。不支持客户端预编辑的目标无法提供此显示行为。

## 验证

隔离 SDK，Qt 6.8.0 / DTK6 / Fcitx 5.1.12-2deepin12 / KWin 4:6.1.38。未修改宿主输入法配置，未在宿主安装新包。

- 25 个 CTest 组件最终通过。完整运行首次 24/25，唯一失败为启动默认输入法测试的固定等待竞态：它在 GUI 真正应用偏好之前就因旧输入法已是拼音而继续。测试先设英语、等待 GUI 切换到偏好拼音和恢复可编辑状态后再检查切换是否保留；该用例单测及整个失败组件复跑均通过。保留首次完整日志和复跑日志。
- 包含 X11、嵌套 Wayland 文本输入 v2/v3 的光标预编辑/选词替换；使用有效拼音配置 `PreeditMode=Do not show` 验证覆盖和恢复；新增用例先失败后修复通过。
- 状态单测 16 项，覆盖双 Shift、修饰组合、取消、长按及间隔边界。QML 浅色/深色、桌面几何、浮动卸载重建、Space 拖动和既有候选/安全输入/实体键盘可见性/渲染与隐藏资源回收组件通过。
- 仓库 unittest 16 项通过。
- 实际 GTK 编辑目标及真实指针点击：双 Shift 锁定/解除后输入 A/Aa，Space 拖动不提交空格，地球切换到拼音，点击 nihao、展开/还原候选、提交 Aa你好、候选行显隐保留浮动底边、打开设置和收起均通过。
- 实际界面截图：100% 浅/深色及 150%/200% 浅色，空闲与候选状态。
- 只读复核指出隐藏卸载后高度变化可能丢失底边；保留尺寸与输出后新增回归通过，复核无其他具体问题。
