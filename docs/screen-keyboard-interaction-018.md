# 屏幕键盘 0.1.8 拖动、常驻候选行与圆角

2026-10-04。在已确认的 deepin/DTK 外观上，根据用户要求修改交互。基线为 0.1.7（55cf1c1）；实现、截图与原始验证记录位于 `out/components/agino-keyboard-validation/interaction-018/`。

## 最终行为

- 主键、功能键、空白边缘和空候选行支持鼠标及触摸拖动；超过 16 逻辑像素取消当前按键，使用屏幕坐标连续移动。拖动释放后保持窗口位置，隐藏卸载后重新呼出仍保留。候选的水平滑动继续浏览候选，展开区继续纵向浏览。
- 单一拖动所有者取消其他按住键，并禁用候选和设置交互，第二根手指不能提交候选或触发动作。设置界面的空白区域也可拖动，控件本身保留原交互。
- 长按变音字符保留从原键到弹出栏的接近走廊，连续上移仍可选中字符；拖向走廊外移动窗口。
- 候选行固定 48 逻辑像素，无候选时左侧显示 Fcitx Controller 提供的名称和语言；有候选时显示连续候选文字及下拉箭头。预编辑字母仍显示在目标应用的光标处。安全输入显示“安全输入”，无编辑目标显示选择输入框提示。
- 只缓存已配置输入法的元数据，切换时复用缓存；查询失败最多三次退避重试（500/1000/2000 ms），验证完整 `a(ssssssb)` 类型，断线停止。持续失败显示暂不可用，不无限循环；再次查询可恢复。
- 候选出现、选择及消失均不改变窗口、键位高度和位置。最小窗口为 828 × 344；设置主区域保持 296 高。测试机 200% 缩放下默认 934 × 344 逻辑像素，即 1868 × 688 物理像素。
- 原生窗口清底色设为透明，由 QML 主面板绘制 12 逻辑像素圆角，避免不透明窗口填满四角。
- 退格改为与地球、收起按钮同线宽的矢量轮廓，独立于字符字体；辅助名称为“退格”。轻点抬起时删除，长按 450 ms 后开始成对连删，每 60 ms 一次；初始拖动或取消不删除，已发生的长按连删不回滚。

## 验证

- 最终完整组件测试 26/26 通过，仓库 unittest 16/16 通过。
- 新回归先复现旧代码的字母键拖动无效、候选行隐藏、透明圆角缺失和无自动状态；再验证修复。
- 退格按下即删除的问题先以状态机取消及拖动用例复现；轻点、连删边界、取消和停止后不再发键均通过。
- 模拟触摸验证字母键拖动及轻点输入，真实两触点序列验证拖动时第二指不提交候选；候选滑动不移动窗口。
- 连续多段鼠标移动验证选择变音字符，避免单步跳入弹出栏掩盖走廊错误。
- 独立私有 DBus wire 夹具先复现 Controller 错误和畸形回复无法恢复；修复后自动恢复、三次重试上限及手动恢复通过。真实 Fcitx 验证中文/英文输入法状态随切换更新，无需进入设置。
- X11 和嵌套 Wayland 的原生指针测试从数字键开始拖动，验证连续位置、无输入、目标焦点保留、隐藏卸载后位置恢复。
- 组件窗口测试验证四角透明、中心不透明；八张实际截图（中/英文无候选、有候选、设置，各浅/深色）全部为相同尺寸，四角 alpha=0、内部 alpha=255。

截图来自本机 Qt/DTK 运行时、隔离 Xvfb/私有 Fcitx 会话，截图会话使用中文 locale；未解锁或操作用户桌面。测量使用 C.UTF-8 会话便于与历史实验复现。GUI 截图/测量使用相同 SDK 构建的未 strip 版本；交付为该构建 strip，两个 SHA 记录于 package-provenance.json。

## 安装包与范围

基于 0.1.7，只替换 GUI、应用 README 和插件版本配置；其余载荷字节相同，Depends 相同，无 LayerShellQt。安装模拟仅升级 agino-keyboard、不新增系统包。本轮未在用户会话安装。源码、匹配上游源包、补丁与许可证一起分发。

安装后先完成当前组合，注销并重新登录，以退出旧 GUI、加载匹配的输入法插件。真实触屏/笔与完整 DDE Wayland、旋转、热插拔、休眠未在本轮验收；模拟触摸和嵌套协议测试不能替代设备验收，release_ready=false。
