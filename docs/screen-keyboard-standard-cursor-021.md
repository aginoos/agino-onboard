# 0.1.21：恢复标准Qt光标

用户明确选择：不使用轻量静态光标优化，恢复Qt标准处理。此选择优先于继续追求光标缓存的约MiB级内存收益；不引入QtWayland补丁、定制Qt库、独立Wayland光标管理器或固定内置箭头。

## 源码与构建

NativePanel不再构造NativeCursor或设置自定义位图。移除轻量光标类、主题继承解析、Xcursor动态加载、轮询计时器、缩放判断、专属测试和探针；CMake移除对应静态库/测试目标及Xcursor pkg-config检查，构建脚本不再显式添加libxcursor-dev。旧源码和探针可在Git提交62606600及0.1.20完整源码包追溯，历史说明保留并标明版本。

Qt自行选择系统主题、动画、输出缩放、热点及服务端cursor-shape协议路径。正式界面仍为QtGui/QPainter，未恢复Qt Quick；0.1.20恢复的正常字体缓存复用，以及收起后退出界面进程的机制均保留。Qt系统依赖/private ABI约束仍由其他现存平台接入决定，不因删除这个组件而任意放宽。

## 验证方法与进度

新增真实Wayland窗口回归：标准和紧凑模式在显示、超过旧轮询间隔的停顿及重新显示后，保留Qt::ArrowCursor且无应用自定义pixmap；分别在真实1×/2×输出运行。测试先在旧实现确认失败：实际为BitmapCursor，期望ArrowCursor；不以编译错误代替红测。

后续记录实际构建、完整CTest结果、包校验与包内程序运行采样。旧版--verify-no-cursor-atlas是历史断言，不适用于本版；Qt标准主题缓冲出现属于预期，不能再当作回归。

## 历史增量测量的解释

在当前默认主题、24逻辑像素基准光标的小型隔离QWindow中，默认Qt相对选择性加载的RSS/USS/PSS增量为：1×约0.58/0.84/0.81MiB，2×约1.50/1.92/1.92MiB。两种路径的实际静态箭头像素与热点一致。该结果不是整个键盘的端到端差值，其他主题/动画帧数/光标尺寸会改变增量。

原始记录：out/components/agino-keyboard-validation/cursor-qt-default-020/，本轮发布证据另存out/components/agino-keyboard-validation/native-021/。本机用户应用不自动安装或重启。
