# Agino 屏幕键盘首版设计

日期：2026-10-03。状态：用户已确认架构与 DTK 风格，要求改用标准物理键盘布局；
用户已于 2026-10-03 确认方案五，进入实施。
本文件不代表产品已实现或通过验收。

## 目标与已确认范围

用户要求开发与输入法结合的屏幕键盘应用，包含触屏和 Wayland 支持；已确认首版
主要面向桌面与二合一触屏设备。应用随 Agino OS 集成，支持实体键盘、鼠标和触屏
混合使用，复用现有 Fcitx5 中文输入法与用户词库。
用户进一步要求参考 Deepin 其他应用的 DTK 风格，必要时使用 DTK 控件。
布局参考 Windows/macOS 屏幕键盘；数字行默认显示，F1–F12 功能行可在设置中开关且默认隐藏。
最新要求以用户附图的窄标题行结构为参考：最左设置图标、中间「屏幕键盘」、最右关闭按钮，
移除底行设置和关闭键；呼出模式统一放在设置窗口。保留正确对齐的方向键、中/英移位和候选展开覆盖，
候选行与展开面板都必须按候选内容自适应宽度。

成功标准是能够向当前应用可靠输入中英文、选择候选词，触屏输入时自动呼出且
不抢走应用焦点，实体键盘输入时收起；同一界面在 X11 和 KWin Wayland 下使用。
Wayland 支持必须验证真实文本提交、窗口角色和触控行为，不能用 XWayland 窗口
显示成功替代原生 Wayland 验证。

## 项目证据

当前桌面原型使用 Deepin 25、DDE、KWin 和 LightDM，默认启动 X11。软件包记录为：

- `fcitx5` / `fcitx5-modules`：`5.1.12-2deepin12`。
- `fcitx5-chinese-addons`：`5.1.6-3deepin0`。
- `kwin-wayland` / `kwin-x11`：`4:6.1.38`；`dde-kwin`：`6.0.9`。
- Qt6 Wayland：`6.8.0-0deepin15`。

原型包含 `libvirtualkeyboard.so` 和对应 addon 配置，配置声明为按需加载的
`OnScreenKeyboard` UI。现有 rootfs 没有 `/usr/share/wayland-sessions` 入口，
已配置的窗口管理器服务是 `dde-session@x11.service`。
这些证据说明具有可研究的后端基础，不说明 Wayland 桌面已经可用。

Fcitx5 上游 5.1.12 提供按键、候选选择、翻页、预编辑与输入法状态回调；按键
后端要求存在有焦点的输入上下文。普通键盘界面不能创建自己的输入上下文来替代
目标应用，否则文本将提交给键盘本身。

## 方案比较与选择建议

| 方案 | 优点 | 代价 |
| --- | --- | --- |
| 独立 C++ / Qt6 / QML 界面，接入 Fcitx5 虚拟键盘后端（推荐） | 与 DDE 技术栈一致，可独立维护触控交互，沿用输入法和词库 | 需要实现协议适配、非聚焦窗口及桌面集成 |
| 改造 fcitx5-osk | 已有 Fcitx5 接入、布局和 KWin 集成经验 | 上游主要实测 KWin6 Wayland/XWayland；修饰键方案和 Deepin 兼容性仍需核实，引入额外运行时 |
| 改造 clear-code/fcitx5-virtualkeyboard-ui | 基于 Fcitx5 原生 UI，支持多语言 | 主目标是 Weston，上游记录 X11 尚不完善，旧版本依赖额外补丁，需重做桌面适配 |

建议采用第一种方案，应用命名为 `agino-keyboard`。不另造拼音引擎，不引入浏览器
运行时。普通用户会话运行，不增加系统级键盘注入服务。

## 界面和触控行为

视觉遵循 Deepin DTK6 / Chameleon 风格。当前原型已安装
`libdtk6declarative 6.7.47.2` 和 `qml6-module-qtquick-controls2-styles-chameleon`，
`org.deepin.dtk` 的控件目录提供 ApplicationWindow、ControlBackground、ToolButton、
Menu、Switch、Slider、ComboBox 和 Label，首版实际使用这些控件和主题接口。

背景、文字、按下态、强调色、字体和边框从 DTK 系统调色板与字体接口取得，
响应系统深浅主题切换。设置页采用 DTK ApplicationWindow、TitleBar 与标准设置
控件；键盘面板采用适当的非聚焦窗口角色，其内容复用 DTK 风格与控件。
DTK 外观不改变合成器授予的窗口角色。触屏按键定制交互，至少 48 逻辑像素，
不直接沿用普通桌面按钮的默认高度；保持清晰候选条、适度圆角和一致间距。
普通面板控件禁止通过点击取得键盘焦点；设置页允许取得焦点，并先暂停键盘发键。
模糊与阴影按合成器能力启用，缺少效果时仍使用一致的不透明系统配色。
增加深浅主题、强调色、字体变化及不抢焦点的视觉和交互验收。

默认底部停靠，候选条位于按键上方，仅在存在预编辑或候选时显示。
键盘面板顶部增加一条窄标题行，其结构由用户附图参考并按明确要求调整顺序：
最左为设置齿轮图标，整个面板正中为「屏幕键盘」，最右为关闭 ×。
标题行视觉上窄于普通键行，图标具有可靠触控区域；不添加自动下拉、最小化按钮或其他工具。
设置图标打开 DTK 设置窗口；关闭按钮收起本次键盘、取消按键并清除候选展开状态，
不修改呼出模式或退出 Fcitx5，按既定手动隐藏策略避免同一焦点周期立即重弹。
采用标准 QWERTY 布局，英文与拼音共用；默认五行，打开功能行后六行：

1. 可选功能行：Esc、F1–F12、Del，F1–F4、F5–F8、F9–F12 分组，默认隐藏。
2. 数字行：反引号、1–0、减号、等号和退格；同时显示常用 Shift 符号。
   功能行隐藏时，数字行最左侧加 Esc，保留反引号键。
3. QWERTY 行：Tab、Q–P、方括号和反斜杠；功能行隐藏时，Del 紧接在反斜杠键右侧。
4. 主字母行：Caps、A–L、分号、单引号和 Enter。
5. Shift 行：Shift、Z–M、逗号、句点、斜杠、右 Shift、向上方向键、中/英。
6. 底部行：Ctrl、Super、Alt、空格、右侧修饰键和左右下方向键；无设置键或关闭/收起键。

功能行可见时，Esc/Del 移回功能行，不在数字/QWERTY 行重复显示。
「显示功能键行（F1–F12）」开关属于设置窗口，默认关闭，不是底部 Fn 修饰键。
数字行默认完整显示，不能要求先切换到数字页或 Fn 层；普通数字和标点
直接由对应按键输入，不再用「123」页替代数字行。设置入口仅在窄标题行左侧。
F 键按标准功能键发送，不默认为音量/亮度等媒体操作。
方向键维持倒 T 字，整组相较三稿左移一格；↑ 与 ↓ 的水平中心和键宽一致，
↑ 右侧原有空位用于中/英切换，不在底行重复中/英。右侧末段上排依次为右 Shift、↑、中/英，
下排为 ←、↓、→，右 Shift 可向左延长。
整体相较三稿收窄约一列普通键宽，普通字母/数字键保持尺寸；收回三稿右端退格、Del、Enter
的部分加宽和移走底行中/英后腾出的空间，不同比缩小全部按键，不删除右 Shift 或标点。
五稿移除底行设置/收起键后，原有键盘宽度保持，腾出的空间用于空格和修饰键布局。
支持用户已有 Fcitx5 输入法列表；不承诺每一种第三方引擎都有专用键盘布局。

按键最小触控区域为 48 个逻辑像素；默认高度目标为可用屏幕高度的 40%，
支持高度设置和横竖屏重新布局。当前可见按键行、候选条与间距决定最小实际高度；
低分辨率或大缩放下以触控尺寸和完整默认布局为先，必要时超过 40% 并显示实际生效尺寸，
不缩小触控区域或静默隐藏数字行/用户已开启的功能行。超过屏幕可容纳尺寸时明确提示需要调整缩放。
多显示器优先跟随有焦点应用所在输出；拔插显示器、改变缩放和旋转时取消当前
触控，再重新定位。提供手动切换目标显示器，以应对无法取得目标输出的环境。

每个触点独立记录按下的键，支持 Shift 与字母同时触摸。按下/释放必须配对；
触控取消、窗口收起、切换应用、休眠及后端断开都终止重复输入并清除按键状态。
退格在持续按住 450 ms 后以约 60 ms 间隔重复；长按字母/符号显示备选字符，
拖出按键且未选中备选项时取消，避免多指操作变成鼠标重复事件。
这些时间常量可在实机验收后统一调整。

候选条显示真实 Fcitx5 预编辑和候选项，支持左右滑动显示其他候选，取消左右翻页按钮。
右侧只保留一个向下箭头，点击后在候选条下方以候选网格覆盖整个按键输入区域；
候选条和该箭头保持可见，展开状态仍用向下箭头并高亮，不改变窗口位置或面板尺寸。
选中有效候选后还原键盘；再次点击该箭头也还原键盘，不另设完成按钮。
展开时下方键盘不接收点击，切换焦点/后端失联/锁定时关闭展开并清空内容。
展开面板采用自动换行的候选按钮流，支持纵向滚动；候选按钮按内容实际排版宽度加统一内边距
计算宽度，单字、词组、长短语不能强制使用等宽网格。高度保持统一的最小触控尺寸；
超出一行可用宽度的单个候选在按钮内换行，不截去辨识候选所需的内容。
候选条同样按内容实际排版宽度加统一内边距排布并横向滚动，词条从左侧连续排列且间距一致；
不得使用均分布局、固定宽度网格或拉伸每个候选来填满整行。单字、2字词、3字词和长短语
必须在默认候选行中体现不同宽度，而不仅在展开面板中体现。右侧剩余空间保持空白。
展开箭头为独立右侧控件，不与候选文本混排。
列表与候选流按需绘制，不为大量候选创建等量 QML 控件。
分页引擎按滑动位置按需请求其他页，必须保持候选身份映射，不能把旧页内索引当成新页索引。
切换目标应用或后端重启后立即清空旧
候选，不允许旧索引提交给新输入上下文。候选选择必须先确认当前列表仍有效。

## 呼出策略

设置窗口包含「呼出方式」分组，提供「自动」「手动」「关闭」三个模式，默认自动；
键盘面板不再单独提供此下拉。其他设置为功能行显示开关、显示高度/屏幕/系统主题、当前输入法、
安全输入和快捷呼出，沿用 DTK 标准控件。窄标题行最左的设置图标打开此窗口。
手动入口通过应用菜单和托盘
提供，快捷键可配置。关闭模式不接受输入法自动显示请求；手动模式仅由用户呼出。

自动模式规则：

1. 最近操作来自触屏或平板笔，且目标输入上下文可编辑时呼出。
2. 单纯鼠标点击不呼出；二合一设备的平板姿态可作为补充信号，但设备存在触屏
   本身不是自动呼出的理由。
3. 实体键盘输入时收起；屏幕键盘自身生成的输入不得被识别成实体键盘事件。
4. 用户手动收起后，同一个焦点周期内保持隐藏，下一次明确触屏进入输入框可呼出。
5. 没有可编辑焦点时停止发键；手动打开允许保留面板，并显示等待选择输入框的提示。

设备来源由桌面适配器提供，输入焦点由 Fcitx5 / 合成器提供，不通过扫描应用文本
或轮询全局鼠标位置猜测。KWin 上游具有最近触屏/平板输入判断；Deepin 分支及
Fcitx5 模块的实际协作需要运行验证。必要时增加小型 Fcitx5 会话 addon，只转发焦点、
输入用途、后端代次和物理键盘状态，不转发应用正文。

无法可靠获取设备来源时，明确提供手动模式并报告缺失能力；该情况不算该环境的
自动呼出验收通过。首版 X11 自动模式需结合 XI2 触控来源和输入法焦点验证。

## 组件与输入路径

- **Qt6/QML 界面**：布局、候选显示、主题和触点处理，不承担输入法运算。
- **输入控制器**：按键配对、Shift 状态、重复输入、候选代次、显示状态机。
- **Fcitx5 适配器**：单实例 D-Bus UI，按键发送到当前应用的真实输入上下文，
  接收候选/预编辑和输入法变更；监控后端服务所有者并在重连时重新初始化。
- **桌面适配器**：分别处理 X11 与 KWin Wayland 的非聚焦窗口、屏幕位置、
  可用区域和自动显示信号；在 UI 中提供实际能力状态。
- **会话与打包**：Debian 包、启动入口和会话配置，不重复启动第二个 Fcitx5。

主要输入路径为：触点 → 输入控制器 → Fcitx5 虚拟键盘后端 → 当前输入法 →
目标应用。候选和预编辑沿 Fcitx5 回调返回界面。
界面接收 Fcitx5 调用的协议名称、对象路径及方法签名以安装包的实时 introspection
和匹配源码为准，不能只照抄最新主分支接口。与已有虚拟键盘争用 D-Bus 名称时
给出明确提示，不替换其他进程的服务所有者。

X11 优先使用 Fcitx5 输入路径。对于未接入输入法的 X11 目标，按需采用 XTest
兼容路径，将按键交给目标应用和它的输入法正常处理；单次按键只选一种路径，
避免重复输入。不向无焦点窗口发键，按当前 XKB 映射生成 keycode。

## Wayland 集成

由 KWin 启动唯一 Fcitx5 实例，使其获得合成器授予的输入法连接；界面通过
会话 D-Bus 与该实例协作。Fcitx5 保持 input-method 角色所有者，界面不争用
同一个输入法角色，也不能让两个独立 Wayland 客户端复用同一 socket 流。

普通桌面面板优先采用受支持的 layer-shell 非聚焦底部窗口，设置合理保留区域；
Qt6 LayerShellQt 可用性和 Deepin KWin 对该角色的支持是兼容性验证项。
普通 xdg-shell 窗口不能被当作可靠停靠方案。若安装版本不具备所需角色支持，
应提供与目标版本匹配的适配实现并重新验收，不能只设置 Qt 窗口标志便宣称完成。

应用文本协议经 Fcitx5 与 KWin 协作；分别验证原生 Wayland Qt、GTK 和 XWayland
客户端。修饰键、大小写、Tab、Enter、方向键以及未被输入法消费的按键必须
验证实际转发，不能从中文候选提交成功推断这些路径也有效。
发现现有后端转发缺陷时优先研究匹配版本的小型可追溯补丁，不默认引入 root/uinput。

Wayland 使用独立验证会话，先在嵌套 KWin 中验证协议，再在完整 VM 会话验证。
不将默认桌面直接切换为 Wayland；完整 DDE 会话启动、锁定/退出行为若存在
额外阻碍，应单独记录并处理。嵌套测试不能替代完整会话验收。
Wayland 会话的输入法环境单独配置，避免把 X11 的全局 IM_MODULE 设置照搬过去。

## 密码、登录和故障处理

密码/敏感输入框使用英文数字与符号布局，关闭候选展示和词库学习；依赖目标
客户端报告用途并验证 Fcitx5 是否遵守。获取不到敏感标记的环境提供明确的
「安全输入」切换。界面不保存预编辑、候选或用户按键日志；诊断记录仅包括
后端版本、能力、连接状态、错误码和耗时。

首版范围为登录后的普通用户会话。LightDM 登录界面和 DDE 锁屏使用不同的信任
边界和窗口角色，需要独立设计，首版不通过复用普通用户 D-Bus 实例给这些界面发键。
会话锁定时普通键盘隐藏、释放按键并清除敏感状态，解锁后重新取得焦点。

Fcitx5 未启动、模块缺失或后端中断时，停止发键和重复计时器，清空候选并提示
恢复输入法。异步 D-Bus 调用不能阻塞触控；故障恢复时不重放断开期间的旧按键。
隐藏期间停止界面动画与高频刷新，保留轻量会话连接以响应下一次呼出。

## 交付与资源

代码计划位于 `apps/agino-keyboard/`，包含 CMake、运行入口、QML、协议适配器、
桌面适配器、配置和针对状态机/协议的测试。提供独立构建与 guest 构建脚本，
通过现有桌面原型打包流程安装。构建记录软件包、源码/补丁和许可证。
实现时仅修改必要集成位置，并保留工作区中的其他应用开发改动。

分别测量隐藏、显示和连续输入状态的进程占用、CPU 与唤起延迟，并记录新增
软件包及镜像体积。继续使用项目已有的三次冷启动、120 秒稳定期和 60 秒采样
方法验证整机空闲内存上限 1,000,000,000 字节。资源指标尚未实测，不能将 Qt6
或按需加载自动等同于低内存。
