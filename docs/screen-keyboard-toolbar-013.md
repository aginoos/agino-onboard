# 屏幕键盘 0.1.13：快捷键切换与候选行工具栏

2026-10-05。基线 0.1.12（2dab5b3）。构建、测试、截图和包证据位于 `out/components/agino-keyboard-validation/toolbar-013/`。本轮未安装主机包、重启主机输入法或操作用户的输入窗口。

## 行为调整

Ctrl+Alt+K 改为切换显示／隐藏：显示中再按一次收起，收起后再按一次显示。快捷键触发使用独立 Toggle，原 Show 保持幂等，应用启动、输入法呼出和显式显示不误关闭。设置页显示期间也可收起。实体按键释放和普通实体输入不改变键盘显示状态。

候选行左侧常驻本应用的蓝色键盘 SVG 图标，使用现有应用图标资源，标准绘制 24、紧凑 18 逻辑像素。图标区域不抢输入焦点，保留背景拖动路径。

输入法状态移至右端、设置／候选下拉按钮之前，并右对齐。标准模式沿用 Fcitx 的完整语言和输入法状态；紧凑模式从 Fcitx 元数据的语言字段读取缩写，中文显示 CN、英文 EN，其他语言使用相应语言代码（如 JA、DE）。不根据显示名称猜语言；元数据缺失显示破折号，安全输入显示“锁”。有候选词时也保留状态。

候选列表位于应用图标与右侧状态之间，裁切到自己的区域，候选词继续按内容计宽并横向滑动。完整状态宽度最多占候选行 35%，较长名称省略，避免挤出候选区；右端仍在无候选时显示设置，有候选时显示下拉按钮。

设置图标的可见尺寸标准 18、紧凑约 14 逻辑像素，描边基准由 1.6 降至 1.2；点击和拖动区域仍为 48／32，不缩小操作范围。窗口尺寸、Fn、双栏设置、透明度与按键声音沿用 0.1.12。

## 验证

- 新的原生快捷键测试在旧版上因第二次不隐藏而失败，修复后实际 XTest Ctrl+Alt+K 显示／隐藏／显示及按键释放检查通过，并保留目标输入焦点及空文本。
- 新候选行 QML 测试在旧版上因缺少应用图标而失败；语言元数据测试因不存在缩写属性失败。修复后标准/紧凑、左右位置、图标加载、右对齐、语言变化、候选宽度和更小设置图标检查通过。
- 元数据客户端测试覆盖 CN、EN、JA、DE 及缺少语言的情况，使用完整的私有 DBus wire fixture，不把文字解析伪装成输入法状态。
- 最终完整组件回归 35/35 通过（329.38 秒），仓库 unittest 16/16 通过，结果见 ctest-final.log、repository-tests-final.log；独立只读审查未发现新的具体问题。
- 实际 GUI 截图来自交付 deb 对应的 strip 二进制，运行在匹配 Qt/DTK SDK、私有 Fcitx/GTK 输入窗口和 Xvfb/xcompmgr 桌面。包括中文候选、CN/EN 状态、标准/紧凑、Fn、设置、深色、65% 透明度和 200%，不是设计稿。
- deb 的六个 ELF 无外部 LayerShellQt 链接，运行依赖沿用 0.1.12。主机安装模拟新增包数 0。精确包大小、依赖、校验和源码提交见 package-provenance.json。

源码、匹配上游源码与许可证随预览归档一起提供，不分发搜狗二进制。完整 DDE Wayland、真实触屏/笔、旋转、热插拔及休眠仍需整机验收，本包用于本机测试，release_ready=false。

安装后退出旧键盘再启动新版本；本轮桥接插件代码不变，无需为界面调整强制重启输入法。
