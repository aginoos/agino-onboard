# 屏幕键盘 0.1.10 设置入口与完整设置覆盖层

2026-10-04。基于 0.1.9（a56332e），按用户确认的布局调整设置入口；保留既有 deepin/DTK 风格和输入行为。

## 行为

- 无候选时，候选行左侧保留当前输入法标准状态，右侧显示矢量设置图标；有候选时同一位置显示展开/收回候选箭头。
- 删除第四排的设置按键，左 Shift 从 1.5 单位延长至 2.5 单位，与右 Shift 同宽。该排仍为 15 单位，字母键宽度保持，其余排布局保持。
- 设置覆盖整个窗口，包括候选行和键盘区域。打开时隐藏候选行和键位，返回恢复；候选行的 48 逻辑像素布局高度仍保留，因此打开、返回不改变窗口尺寸。
- 原设置层从候选行下方开始，却按整个窗口宽度绘制，左右各比候选行多 8 像素，造成宽度跳变观感。新覆盖层与面板对齐，内缩 1 像素保留原边框和圆角。
- 候选行设置按钮继续支持鼠标和触摸拖动。超过拖动阈值取消设置动作；拖动期间阻止第二指提交候选或操作其他控件。轻点打开设置，不发送输入按键。

- 使用匹配 deepin 25 SDK 中 Qt/DTK 的实际 GUI，隔离 Xvfb 与私有 Fcitx 会话生成 12 张截图：英文空候选、中文空候选、中文候选、设置，各浅色 100%/200% 与深色 200%。各状态同为 934×344 逻辑像素；200% 为 1868×688 物理像素。四角 alpha=0，内部 alpha=255。
