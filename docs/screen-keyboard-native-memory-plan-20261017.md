最终验收：0.1.19在X11/Wayland均匀1×/2×输出的完整应用对照中，首次、后续及总体各状态USS/PSS中位数通过；RSS仍较高。完整数字与限制见[最终验收报告](screen-keyboard-native-memory-20261017.md)。下面保留按执行顺序记录的中间状态，不能把早期“尚未验收”读作最终状态。

用户已要求持续优化直至达标，保留现有界面和输入行为。基线是0.1.18完整进程对照：200%候选RSS100.71/USS31.95/PSS42.50MiB，Slint20.59/16.00/16.13MiB；普通显示、候选展开、设置和隐藏均需验收。RSS继续争取，不能用共享页解释代替实际优化。

本阶段以QtGui/QPainter原生面板替换QML绘制，不改变Fcitx、KWin、Wayland、输入状态或DTK调色板/字体来源。旧前端保留作基线，实验前端先独立目标构建，未经过完整验收不切换发行包。单一BackingStore按需刷新；确定完整前端成本后再实施必要的分带输出/双缓冲限制，不降低分辨率、颜色或功能。

并行范围：原生按键布局/文字/图标绘制；原生完整设置；惰性Qt无障碍接口。根任务独立负责窗口/拖动/触屏/候选、后端和生命周期接入、集成与最终复核。统一NativeControl/NativeStyle接口，各任务仅编辑自己的文件。使用技能dispatching-parallel-agents分拆独立组件，不改相同文件。

顺序：实现并编译实验目标 → 单元与实际鼠标/触屏/候选/设置/无障碍检查 → 51张界面逐像素对照并修复 → 完整现有原生输入回归及新前端覆盖 → 停止SDK、同条件串行采样全部应用PID → 与Slint逐状态比较，未达标继续定位活跃分配。达到完整功能与资源目标后才切换默认前端、版本与打包，提交本地master。探针数字不算达标。

### 正式候选回归与额外修复

0.1.19正式构建已经改用原生QtGui界面，Qt Quick留作显式参考目标；提示对话框独立安装并纳入shlibdeps。构建脚本从CMake读取版本，默认构建所有注册的原生测试，移除正式包手工追加的QML运行模块依赖。仍未交付或安装新deb。

全56项回归首轮54通过，失败项为旧Qt Quick参考阴影测试一次瞬态失败，以及真实小屏幕布局警告。前者原始测试连续4次复测通过，带截帧诊断5次通过，移除诊断后1×/2×再次通过；未改生产阴影代码，保留原始失败且不冒称瞬态原因已完全归因。后者重复复现，私有配置文件写入compact=false后被窗口状态元数据写回compact=true；原生前端更快显示使既有的重复QSettings写入竞态显现。按实际字符串/列表值去重元数据写入后，原失败用例及生命周期、排队拖动、启动和原生交互共9组回归全部通过。Qt6.8的QSettings::set无条件加入addedKeys，源码依据https://raw.githubusercontent.com/qt/qtbase/v6.8.0/src/corelib/io/qsettings.cpp 。

光标优化额外复核：旧合成器、服务端cursor-shape协议、混合/强制缩放及非绝对XDG数据目录均走Qt原路径。动画箭头也回退Qt，保留原后端的帧回调和时序；仅优化静态箭头。发现并补齐热点除以缓冲scale时QPoint的qRound规则，防止奇数热点被整数除法向下取整。首次最终X11测量因此主动取消，记录保留为canceled-before-odd-hotspot-fix-1x，不纳入最终结果；最终ELF须重新测量。
