# 屏幕键盘 0.1.7 内嵌设置

2026-10-04。用户确认紧凑 deepin 风格设计后，将设置接入实际 QML 应用。设计 skill 使用 ui-ux-pro-max；设计稿为 `out/design/screen-keyboard-inline-settings/`，实际运行与测量证据为 `out/components/agino-keyboard-validation/inline-settings/`。

## 行为

点击第四行最右侧设置键，覆盖主键区显示“键盘设置”，保留候选行。两组四行显示呼出方式、默认输入法、安全输入、快捷键、功能行、高度、屏幕和主题；所有设置在最小 828 × 296 逻辑像素内完整可见。正文 13、分组 11、标题 16 逻辑像素；交互行 48，快捷键选择器按键 44。浅色、深色取 DTK palette，使用连续分组、细分隔线和蓝色强调。

进入设置取消按住键并暂停虚拟输入，返回后恢复输入，不因进入/返回而提交、删除组合或候选。候选条暂不接收选择事件；候选展开、长按变音和设置互斥。收起、锁屏、后端断连、尺寸不足时关闭设置；隐藏三秒仍按旧策略销毁窗口、QML 和字体缓存，重开默认显示键盘。

所有入口（设置键、托盘、DBus Settings、CLI `--settings`）使用同一 KeyboardUi1 进程和窗口，不再启动独立设置程序。关闭模式可进入设置、重新启用；返回后仍按选定模式执行。设置立即保存到原 Preferences；主动修改默认输入法或安全策略会执行对应输入法策略，组合保留承诺针对进入/返回本身。

快捷键通过同一主键区内的选择器选择 Ctrl/Alt/Shift/Super 与字母、数字、F1–F12；至少一个修饰键。避免为捕获物理键而抢走目标输入框焦点。输入法友好名称按需查询 Fcitx Controller，只保留当前已配置项；已打开的列表也响应异步名称更新。屏幕从当前 QScreen 列表获取，保留既有按索引保存策略。

- 使用 [Qt Quick Test 的 TouchEventSequence](https://doc.qt.io/qt-6.8/qml-qttest-toucheventsequence.html) 模拟触摸，实际点击设置、分段、开关、输入法选项、快捷键及返回，确保不生成输入字符。
- 实际 Fcitx/Qt 目标验证打开/返回保留中文组合、候选、上下文代次及焦点，CLI 转发复用进程；隐藏卸载后恢复键盘。
- Wayland 设置仍使用本包 layer-shell，keyboard_interactivity=0，无独立 xdg_toplevel。
- 最终构建完整 25 项测试通过，仓库 16 项 unittest 通过；包括浅色/深色 QML、模拟触摸、实际设置交互及 Wayland 窗口路径，日志随预览分发。

实际截图来自本机 Qt/DTK 运行时、隔离 Xvfb 和私有 DBus/Fcitx 会话，不解锁或干预用户桌面；200% 缩放、无候选 1868 × 592 物理像素、有候选 1868 × 688。GUI 为相同 SDK 构建的未 strip 版本；交付 GUI 由该构建 strip，载入代码和资源一致，二者 SHA 保存在 package-provenance.json。

## 内存实验

首次实现打开设置后返回，PSS 从约 43.4 上升至 59.0 MiB；隐藏卸载后约 35.4 MiB。未把“对象卸载”等同于内存已回收。

`smaps` 追踪显示：未打开的快捷键选择器仍创建 53 个 DTK 按钮，额外堆约 7.4 MiB；设置控件还带入 OpenEXR/HEIF/RAW/AVIF 等图像格式库。依次实验并保存原始数据：选择器 Loader 按需加载；滑杆采用 Qt 模板并保持矩形/圆柄；快捷键与返回按钮采用 Qt 模板及 DTK 配色。GDB 最终确认 `switch_button` 的 DCI 绘制调用 QImageReader，触发整套图像格式库加载；开关也改用 Qt 模板与同一 DTK 皮肤，避免这条不需要的图标链。控件尺寸、绑定及鼠标/触摸行为做回归。

200% 缩放、2560 × 1600 的隔离本机 X11 会话，三个新 GUI 进程各取五次样本，再取中位数：

| 状态 | PSS MiB | RSS MiB |
| --- | ---: | ---: |
| 启动即隐藏 | 10.8 | 49.8 |
| 显示、无候选 | 38.5 | 90.2 |
| 中文组合与候选 | 42.8 | 94.8 |
| 打开设置 | 44.8 | 96.9 |
| 返回键盘 | 44.8 | 96.9 |
| 收起并卸载后 | 29.0 | 78.3 |
| 再次呼出、保留组合 | 43.4 | 95.6 |

与首个内嵌设置实现相比，返回键盘 PSS 从 59.0 降到 44.8 MiB，收起后从 35.4 降到 29.0 MiB。打开/返回设置仍暂留约 2.0 MiB 字体与 QML 分配缓存；收起并重建后，显示时回到约 43.4 MiB。

另做一轮快捷键编辑器测量：打开后 PSS 46.7 MiB，收起卸载后 28.7 MiB；`/proc/PID/maps` 确认未加载 HEIF/OpenEXR 库。该选择器额外约 2.2 MiB 缓存，在收起时回收；这轮单进程结果不与上表三进程统计混合。

数值和方法见分发的 `tests/memory.json`、`tests/shortcut-memory.json`；只计算 GUI 进程 PSS/RSS，不包含 Fcitx、显示服务。未复测整机冷启动内存门槛。

## 安装包与范围

0.1.7 基于已验证 0.1.6 包，只替换 GUI、应用 README 和插件版本配置。其他载荷字节一致；Depends 不变，无 LayerShellQt 依赖。包、源码、匹配签名上游源码/补丁和许可证一起分发。安装模拟只升级 agino-keyboard，不新增系统包；本次未替用户执行安装。

安装后先完成正在输入的组合，再注销并重新登录，保证旧 GUI 和 Fcitx 桥接插件都退出；不要在旧 GUI 仍运行时混用两个版本的设置入口。

完整 DDE Wayland、真实触屏/笔、旋转、热插拔、休眠未在本轮重新验收；嵌套协议和模拟触摸测试不能代替设备验收。本包继续作为本机测试预览，release_ready=false。
