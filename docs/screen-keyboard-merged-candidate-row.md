# 屏幕键盘候选行合并（0.1.5）

2026-10-04，基线为 0.1.4，按用户要求移除独立标题栏。

## 行为

- 候选条左端始终显示设置按钮；无候选词时中间显示“屏幕键盘”，右端显示关闭 ×。
- 出现可显示候选词后，中间切换为小字号、内容自适应宽度的连续候选词，右端切换为候选展开/收起按钮；候选清空或安全输入时恢复标题和关闭按钮。只有预编辑、没有候选词时仍保留标题和关闭按钮。
- 设置和右端操作均保留 48 逻辑像素操作范围，候选文字不被设置按钮覆盖；候选横向滑动和覆盖主键区展开行为继续保留。
- 候选区始终保留 76 逻辑像素高度，主键区位置和按键尺寸不随候选状态改变。去掉独立标题行后最低面板高度减少 48 逻辑像素，窗口仍按原高度设置布局。
- 无候选词时拖动中间区域移动键盘；有候选词时拖动上方预编辑文字区域移动。设置、关闭、选词和横向滑动操作互不覆盖。
- 继续保留 0.1.4 的候选窗口接管、物理输入不收起面板和收起卸载后位置保留行为。

## 安装

sudo apt install ~/Downloads/agino-keyboard_0.1.5_amd64.deb

从已加载 0.1.4 的会话更新后，退出托盘中的旧屏幕键盘进程，再重新打开即可加载新界面。输入法桥接插件与 0.1.4 相同。若从更早版本更新，应注销并重新登录以加载对应的 0.1.4 桥接修复。
